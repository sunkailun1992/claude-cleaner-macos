# 测试与验收规范

统一入口：[AGENTS.md](../../AGENTS.md)。完整本地入口为：

```bash
bash scripts/check.sh
```

合并前在最终提交内容上运行完整入口，推后查看该提交的 CI。目标测试可帮助排错，不能替代最终完整检查。管理员可绕过 GitHub PR/checks 规则，不免除这些要求。

## 安全测试环境

文件测试使用临时根、合成 home、假应用身份和合成路径，结束后仅清理自身临时夹具。包管理器、Keychain、launchd、进程和其他系统动作使用注入替身，断言精确 argv 与失败传播。

禁止在测试中针对真实 home、真实 `.claude`、已登录 Desktop、真实浏览器 profile、Keychain、系统 daemon 或生产账号执行卸载/删除。开发任务不隐含真实破坏性验收授权。发现需要真机破坏性测试时，记录缺口，使用获明确授权的可丢弃环境另做验收。

## 必需行为覆盖

| 维度 | 有意义的断言 |
| --- | --- |
| 默认模式 | preview 不删除、不卸包、不执行系统写动作；`--verify` 只读。 |
| 确认与参数 | `--apply` 要求准确确认短语；取消无清理；`--yes` 不能单用；冲突/危险参数返回错误。 |
| 路径安全 | 空格/中文、叶子链接、父链接、路径穿越、危险根、设备/inode/类型改变、目录替换、权限/枚举错误。 |
| 数据保护 | 默认共享 security/guidance、项目 worktrees、项目说明、Cowork 文件被保留；显式选项只扩大对应范围，不能吞掉仍受保护内容。 |
| 范围准确性 | 仅识别明确应用身份、包、插件版本和 manifest 名称；相似名称及他人/外部资料不被误删。 |
| 系统动作 | 精确包/服务/Keychain 参数、非零、超时、锁定、安装渠道缺失与盘点失败；不读 secret、不 sudo、不 kill 用户应用。 |
| 浏览器显式范围 | 默认六种专属 IndexedDB LevelDB/blob 目录仍人工且不删；开启选项才纳入精确三个 HTTPS origin，覆盖支持的默认根/profile、根自身 profile、blob-only/leveldb-only；相似域名、其他 origin/端口、自定义根、分区/bucket/新版布局不得扩大。 |
| 浏览器边界与进程 | 拒绝父链接、profile/叶子链接、其他 UID、非目录、身份变化与盘点失败；共享 Cookies、History、Local Storage、Service Worker、CacheStorage、官方扩展及其 origin 保持不变。支持范围内每个 family 的主进程/Helper 均阻断，验证执行前新出现进程也能阻断、预览仍列目标、无目录但有进程的 `--verify` 不成功；不关闭或 kill 浏览器。 |
| 人工事项 | 浏览器扩展、共享与未识别站点存储、默认未选择的专属 IndexedDB、MDM、系统注册、自定义范围等保持人工；自动删除成功后 manual 仍在须 `incomplete`/退出 `1`。 |
| 复查与幂等 | 执行后重盘点；残留或未知不算通过；再次运行不会扩大范围或损坏保护项。 |
| 报告 | 计划、结果、保留、人工、问题和复查分开；错误/失败不能被摘要吞掉；公开测试输出不含真实私人资料。 |

测试应能在错误实现下失败，不只复述当前方法返回值。新增自动删除路径至少配一个正例和一个会被误匹配的反例；非平凡缺陷先捕捉原错误，再检查相邻路径。不要通过删断言、放宽匹配或改期望成功来消除失败。

## 分层验收

| 证据层 | 能证明什么 | 尚不能证明什么 |
| --- | --- | --- |
| 源码与静态检查 | 代码符合当前语法和结构要求。 | 实际系统动作或真实清理成功。 |
| 隔离夹具破坏性测试 | 在受控合成数据上验证删除、保护、竞态与失败路径。 | 真实用户环境全套兼容。 |
| macOS 真实只读盘点 | 当前机器上有限元数据盘点能运行，结果与人工观察可核对。 | 任意删除、卸包、Keychain/服务变更已经成功。 |
| CI | 指定提交在实际配置的平台上运行了工作流并得到结果。 | 未运行平台、真实账号或用户资料的验收。 |
| 获授权真实清理 | 某个明确环境、版本与范围执行并完成复查。 | 所有机器、历史副本、浏览器/云端或取证级擦除。 |

初始 `v0.1.0` 的已声明基线为隔离夹具破坏性测试与真实只读盘点，未执行真实已安装全套环境的破坏性清理。后续补充验收时记录日期、平台、安装渠道、所选范围、实际结果和未覆盖项；不要把旧版本的只读证据升级成新版本的破坏性实机结论。

`v0.1.1` 新增的浏览器 IndexedDB 范围尚未完成真实删除和同范围复查。浏览器暂不能退出时，只能记录只读预览和阻断结果，不能绕过进程检查或宣称实删完成。获授权实际执行时使用 `./claude-cleaner --include-browser-site-data --apply --yes`，随后以 `./claude-cleaner --include-browser-site-data --verify` 复查；其他范围选项也必须保持一致。共享存储/扩展的 UI 核对、全部浏览器会话、云端和取证级擦除均不能从这两条命令的有限结果推定。

## 文档与发布复核

检查命令、参数、默认保护、退出码和报告与最终实现一致；检查所有本地链接及 Markdown 表格；扫描提交内容中的真实私人路径和凭据。文档应区分规范要求、已实现行为和实际验证，不能把待做检查写成已经通过。

任何本地检查或 CI 失败都要保留实际输出并继续修复。没有运行、无法运行或仍在运行时如实报告，不用“应该通过”替代证据。
