# 工程护栏

统一入口：[AGENTS.md](../../AGENTS.md)。本项目的删除行为必须能从有限计划解释并复查，不能靠扫描整盘或宽泛名称匹配声称完整。

## 模块责任

| 模块 | 责任与限制 |
| --- | --- |
| Planner | 只在已知根与明确参数内枚举目标，保存身份、保留项和问题；不执行系统清理。 |
| MacSystem / CommandRunner | 用 argv 调用固定命令，盘点明确安装渠道、进程、服务及 Keychain 元数据。受控超时只影响本次命令进程组，不用来 kill 用户应用。 |
| Remover | 只接受规划目标；执行前和递归中验证边界与身份；失败如实返回。 |
| Auditor | 以有限目录和元数据发现浏览器/系统项；默认报告人工。浏览器显式选项只提升精确三个 origin 的安全 legacy IndexedDB 目录；不读取或删除共享数据库，不以扩大范围让复查通过。 |
| CLI | 参数、预览/确认、执行、重新盘点、退出状态与报告；不能把人工项或未知盘点当作清洁结果。 |

## 路径与归属

- 使用绝对规范路径与受限根，拒绝空值、`/`、home 本身、父级穿越和不安全父路径。不能把环境变量或命令输出未经验证直接作为递归删除根。
- 父目录符号链接不遍历；允许处理的叶子链接只删除链接本身，不删除外部目标。应用链接不能仅凭名字认定 bundle 身份。
- 浏览器站点目录是更严格的例外：父路径、profile 或叶子链接均拒绝，不按通用叶子链接规则删除；其他 UID、非目录与无法检查也拒绝。只接受三个 HTTPS 默认 origin 的六种 `.indexeddb.leveldb` / `.indexeddb.blob` 专属目录，不递归删除整个 IndexedDB、profile 或共享存储。执行交给现有 Remover。
- 目标的设备、inode、类型发生变化时停止该操作；规划后确认不能覆盖新出现的目标。重新规划发现范围变化时需退出，让用户查看新的计划。
- 目录中的链接、挂载点、他人 UID 和共享临时根需要独立边界。`/tmp` 是动态发现根，不是删除目标。
- 明确保留路径优先于父目标。不能通过删除父目录吞掉 `security`、Git `worktrees`、人工项或未授权用户资料；也不能让自定义根绕过同样保护。
- 路径不存在和无法检查是不同结果。权限错误、目录读失败、解析失败或未知类型要保留并报告，不能吞异常后当作 absent。

## 系统动作与兼容

命令使用参数数组，避免 shell 字符串、`eval`、命令替换和拼接用户输入。只执行明确的包/服务/Keychain 动作，不运行环境发现出的任意可执行脚本，也不读取用户凭据 helper 输出。

保持 Bash 3.2 启动兼容与 Ruby 2.6+ 标准库兼容。不引入网络安装、自动升级、第三方运行依赖、sudo 或系统安全策略修改来填补清理范围。

Homebrew、npm、native、IDE 内嵌 CLI 分别盘点，命令失败分别报告。禁止全局包管理器 cleanup/autoremove、清空共享 cache 或卸 Node/Python/Homebrew 等依赖。未知渠道转人工。

## 结果契约

默认 preview；`--verify` 只读；`--apply` 保留明确确认，`--yes` 仅作为显式无人值守参数。相关程序运行、盘点错误或计划变化不能静默继续。

`--include-browser-site-data` 不改变默认人工边界；仅显式开启时纳入 [coverage.md](../coverage.md#浏览器专属-indexeddb-的精确范围) 的范围。支持范围内的 Chromium 浏览器 family 及 Helper 必须全部退出，执行前重验；有运行进程或无法盘点时阻断执行，`--verify` 也不能成功，即使没有目录候选。预览仍可展示目录和阻断信息，不能关闭或 kill 浏览器。执行与复查使用同一组选项。

共享 Cookies、History、Local Storage、Service Worker、CacheStorage、官方扩展、未知 origin、自定义位置和分区/bucket/新版布局继续人工处理。报告不得把有限 IndexedDB 目录删除写成清空全部站点数据或浏览器会话；实际报告保留在本机私密位置，不进入仓库。

报告同时保留计划、执行结果、重盘点、保留项、人工项和边界。自动删除完成但人工项仍在时必须 `incomplete`/非零；只读复查发现这些项目仍为 remaining。不能删除人工发现逻辑、降级失败或改摘要文案来制造成功。

新增用户行为时，同步 [coverage.md](../coverage.md)、[sources.md](../sources.md)、README、帮助、CHANGELOG 和测试；不复制第三方清理代码或照搬未经验证的路径。
