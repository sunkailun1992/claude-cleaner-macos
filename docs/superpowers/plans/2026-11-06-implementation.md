# Claude 清理器实施计划

> **For agentic workers:** 按模块实施并独立复核，验证证据先于完成声明。

**Goal:** 交付可预览、可执行、可验证的 macOS 本机 Claude 清理脚本与公开仓库。

**Architecture:** 路径盘点、路径删除、系统适配器和 CLI 分离；清理仅执行固定清单。

**Tech Stack:** 系统 Ruby 2.6+、Bash 3.2、Minitest、GitHub Actions。

**Spec:** `../specs/2026-11-06-claude-cleaner-design.md`

## 全局约束

- 无网络下载执行、无第三方运行依赖、无默认提权。
- 默认 dry-run；修改仅在 --apply 明确确认后进行。
- 本轮开发仅沙箱删除和真实环境只读盘点。
- 保留共用目录与 Git worktree；不导出私人材料。

## 重点复核

- 父路径链接或盘点后换成链接时拒绝删除。
- 自定义配置不能把 home、项目根或系统目录变成清理目标。
- npm/brew、钥匙串、launchd 参数必须精确且不经 shell 拼接。
- 权限失败、残留或检测失败必须导致非零退出。
- 新安装渠道和浏览器共享存储不得被误报成已完全清除。

## 任务

- [ ] 编写路径盘点失败测试，再实现固定清单和保护规则。
- [ ] 编写删除失败测试，再实现链接安全、身份重验和逐项结果。
- [ ] 实现系统只读盘点、精确清理命令、CLI 与双击入口。
- [ ] 补充安全/测试/贡献/维护者规范，来源、限制与使用示例。
- [ ] 运行完整本地检查、沙箱端到端和真实只读预览，独立代码审查。
- [ ] 建公开仓库、提交推送、配置贡献规则并读回，等待 CI 完成。
